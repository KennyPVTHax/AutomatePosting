# AutomatePosting

Personal, VPS-hosted video processing and multi-platform publishing project.

## Repository status

**Source import in progress.** This repository is **not yet** the complete or production-ready VideoBot v7 application. Do not deploy until the full source is committed and validated.

The intended application includes a browser dashboard, direct video upload, authorized public-URL import, optional watermark and ending media, video processing, scheduling, and platform integrations.

## Security

Never commit `.env`, OAuth client secrets, access/refresh tokens, `channels.json`, private keys, generated videos or customer data. This is a **public** repository.

## Deployment

Production deployment is pending. Existing NEMESIS and SpreadBot VPS services must remain untouched.
